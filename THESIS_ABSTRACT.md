# Bachelor Thesis Abstract

**Title**: Configuration, Testing and Verification of SM9 Identity-Based Cryptographic Signature Protocol

**Author**: Yuxian Wu  
**Supervisor**: Associate Professor Yuquan Zhang  
**Institution**: Qilu Normal University, School of Information Science and Engineering  
**Period**: September 2021 -- June 2022

## Abstract
This thesis studies the SM9 identity-based digital signature algorithm specified in the Chinese national standard GM/T 0044. Based on the JPBC pairing-based cryptography library, the project configures and runs an existing Java implementation of the signature module, including key generation center setup, private key extraction, signature generation and verification.

Beyond basic functional configuration, the thesis focuses on boundary scenario validation and input robustness. It designs test cases covering normal paths, boundary inputs and exception conditions, and discusses the limitations of pure black-box functional testing for cryptographic protocol correctness.

**Keywords**: SM9, identity-based cryptography, software testing, black-box testing
